## LAHER BAKERY DISTRIBUTION MANAGEMENT SYSTEM

A C# desktop application developed to support the management of laher bakery distribution operations

## TECHNOLOGIES
-  C#
-  .NET
-  Microsoft SQL Server
-  API
-  Twilio
-  Visual Studio

## KEY FEATURES

1. Order Placement
2. Quotation generation
3. Geolocation
4. Order Scheduling & Processing
5. Order Tracking
6. Delivery Notification
7. Invoice & Report generation

The system  allows the distributor to schedule the customer orders to be fulfilled allowing the company to prevent overproduction or shortages.
